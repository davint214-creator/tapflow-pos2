What the site can do

One site — six production systems.

Admins manage the catalog. Staff run the register from any device. Customers pay at the counter or by scanning a QR. Every dollar is verified and logged before a receipt prints.

📦

Admin Dashboard

Create, edit, delete products with name, description, price, inventory, category, location, SKU. Inventory only decrements after a captured payment — pending/refused leaves stock untouched.

  • ✓ Real database (SQLite) — not browser storage
  • ✓ Location filters (Gate / Food Court / Gift Shop / Arcade)
  • ✓ CSV-ready catalog
💳

Real POS & Card Readers

Staff pick products, see tax/total, enter an Adyen Terminal ID and hit Charge on Adyen Reader. The POS calls /api/terminal/pay → Adyen Terminal API lights the physical reader — chip/tap/swipe. Status updates live: pending → captured/refused.

  • ✓ Adyen Terminal API sync
  • ✓ Works with P400Plus, S1E/S1F, others
  • ✓ Duplicate reference blocked (409)
  • ✓ Refunds via Adyen (manager/admin)
🔗

QR Code Checkout

For lines or phone-first guests: generate a QR from the current cart. Customer scans → pays on their phone via Adyen Drop-in (cards, Apple Pay, Google Pay). POS polls the QR session — staff hand over goods only when webhook confirms paid.

  • ✓ Adyen Checkout Sessions
  • ✓ QR expires in 15 min
  • ✓ Same transaction table as counter sales
  • ✓ Polling + webhook verification

What you need to go live with real money

  2. API Key + Client Key — Developers → API credentials → copy

How the RFID pad works

Any USB RFID reader in “keyboard wedge” mode works — ACR122U, Elatec, Parallax, cheap 125kHz USB, etc. Plug into POS computer → cursor in any UID field → tap card → reader types the UID + presses Enter. No driver. For arcade games, use the same card at readers/gates. For top-up, staff taps here then hits Load (cash/terminal).

POS tap-to-load flow: In POS, add Arcade Top-Up button below, or sell any product then tap card → choose amount → collect payment → card balance updates instantly + transaction logged.

Other Compatible Readers

TapFlow uses Adyen’s Terminal API, but the architecture supports any cloud terminal that exposes a sync payment endpoint. To add another provider (Stripe Terminal, SumUp, Zettle, etc.):

  • Implement a provider adapter in server.js → adyenTerminalPayment() (swap fetch URL + headers)
  • Store provider credentials in Settings (same table) and select provider per terminal
  • QR checkout already provider-agnostic — just swap the Sessions call
// Add a provider in 30 lines async function stripeTerminalPay({amountCents, terminalId}){ return await stripe.terminal.readers.processPaymentIntent(terminalId, { payment_intent: await stripe.paymentIntents.create({amount: amountCents, currency:'usd'}) }) }
